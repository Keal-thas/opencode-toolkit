- **Oracle/Loki singleton first-time-startup race (deferred).** If two worktrees both race to bring up a shared Oracle/Loki container for the very first time ever on a machine (started manually now, not by `docker/dev.sh` — see `docker/notes.md`), one `docker compose up -d` succeeds and the other gets a real, non-zero-exit `Conflict: container name already in use` error. - **Docker image tag (`opencode-toolkit-dev:latest`) build race across worktrees (deferred).** The image is deliberately global/shared across all worktrees (rebuilding a multi-GB toolchain image per worktree would be wasteful) — so it sits outside the per-worktree isolation `docker/dev.sh` gives everything else. If two worktrees have different uncommitted `Dockerfile` content and both run `docker/dev.sh build` around the same time, whichever finishes last silently wins the `:latest` tag — the other's successful build just becomes untagged/dangling, and that worktree's next `docker/dev.sh run` quietly uses someone else's image instead of the one it just built, with no error.

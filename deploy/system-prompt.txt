# Windows paths
Bash commands accept Unix-style paths (`/c/Users/...`). The read tool accepts either style. The write, edit, and apply_patch tools need Windows-style paths (`C:/Users/...`) for any path they touch — a Git-Bash-style `/c/Users/...` resolves against the wrong drive (e.g. `C:\c\Users\...`) instead of the intended file.

# Scratch files
`local/` and `.local/` are gitignored personal scratch space — safe to write to, never safe to delete or assume empty without checking first (`tree -la`); ask before removing anything there. Name everything underneath in English kebab-case under `local/<category>/<task-slug>/`, e.g. `local/optimize/lsp-encoding-fix/notes.md`. Category is optional (`optimize/`, `investigation/`, `diagnostic/`, `debug/`, `setup/`, `export/`); the slug should name the actual task (`lsp-encoding-fix`, not `fix`, `temp`, or non-English text).
